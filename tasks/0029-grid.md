## Goal

Grid commands render like List commands: `Grid` (311 extensions),
`Grid.Item` (`content`, `title`, `subtitle`, `accessory`, `keywords`,
`actions`, `quickLook`), `Grid.Section`, `Grid.EmptyView`, `Grid.Dropdown`
(+ Item/Section), `Grid.Inset`, `Grid.Fit`, `Grid.ItemSize`, and props such
as `columns`, `aspectRatio`, `fit`, `inset`, `isLoading`,
`searchBarPlaceholder`, `onSearchTextChange`, `pagination` (record),
`onSelectionChange`.

## Context

- Mirror the List implementation (`packages/runtime/src/api/list.ts`,
  `List.Dropdown`) and scene conventions (`docs/architecture.md`): host
  element types are the public paths, element props render into `Slot`s.
  `Grid.Item.Props.content` accepts an image-like or `{ color }`/`{ value,
  tooltip }` forms — serialize faithfully.
- Enum values from `compat/raycast-api/index.d.ts` (prefer the enum generator
  in `scripts/compat/generate-enums.ts`).
- Reuse the CLI's `search`/`dropdown`/`action` script commands (they should
  work for Grid too; extend if they assume `List`).
- `@covers`, `bun run compat:report`, `bun run corpus:smoke` (one curated
  command uses Grid), commit reports after `bun run fmt`. Other workers build
  launch/window APIs (0028) and MenuBarExtra (0030) in parallel; avoid their
  files.

## Acceptance

- [ ] `bun run verify` passes.

## Out of scope
