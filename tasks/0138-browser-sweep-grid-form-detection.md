## Goal

`bun run site:sweep:browser` stops reporting rendered grids and forms as
`empty`, so `compat/BROWSER-SWEEP.md` shows the real number of blank commands.

## Context

- `examples/browser-demo/browser-sweep.ts` decides content with `.rows li`,
  `.detail` and `form input[data-field]`, both in the settle wait inside
  `runCommand` and in the `page.evaluate` snapshot.
- Since 0135, `examples/web-launcher/render.js` draws grids as
  `<ul class="grid">` rows of `button.grid-cell`, not `.rows li`. Form
  fields carry `data-field` on `input`, `textarea` and `select`
  (render.js around line 155), so `form input[data-field]` misses text areas,
  dropdowns and tag pickers.
- Examples currently reported `empty` that render a `<Grid>` or a `<Form>` with
  no plain text input: `random-color/select-color`, `pinch-svg/grid`,
  `tiny-tycho/index`, `hyrule-compendium-search/broadSearch`,
  `multi-ai-chat/multi-ai-chat`, `leap-new/generate-app`.
- Regenerate the report with
  `PLAYWRIGHT_BROWSERS_PATH=<repo>/.cache/ms-playwright bun run site:sweep:browser`
  (the env var is given to you in the shell; never write its value into a file).
  It writes `compat/browser-sweep.json` and `compat/BROWSER-SWEEP.md`.

## Acceptance

- [ ] The sweep's content marker and snapshot count grid cells
      (`.grid-cell`) as rows and any `[data-field]` inside the scene's form
      as a field.
- [ ] `classifyBrowserOutcome` input gains a `cells` count (or the grid cells
      are folded into `rows`); `browser-sweep.test.ts` has cases for a grid
      with cells → `rendered`, a form whose only field is a text area or
      dropdown → `rendered`, and an empty grid with no empty view → `empty`.
- [ ] `compat/browser-sweep.json` and `compat/BROWSER-SWEEP.md` regenerated by
      the script, not by hand. The `empty` total is lower than 74 and at
      least `random-color/select-color` and `pinch-svg/grid` are no longer
      `empty`. List in Handoff every command that left `empty` and its new
      outcome.
- [ ] `bun run verify` passes.

## Out of scope

- Launch modes (`no-view`, `menu-bar`): task 0139.
- Changing `render.js`, `client.ts`, or any runtime behaviour.
