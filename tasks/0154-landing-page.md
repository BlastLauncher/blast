## Goal

blast.yukai.dev's landing page sells the engine to app builders: one glance
shows how small the integration is, that it works from any language, and
invites them to try the live demo and then embed.

## Context

- The page is generated by `landing()` in `examples/browser-demo/site.ts`
  (inline HTML/CSS, light and dark). Stats come from `extractStats`.
  `bun run site:build` writes `.cache/site/www`; `site.test.ts` and
  `site-e2e.ts` cover it. Move the landing markup/CSS into its own module
  (e.g. `examples/browser-demo/landing.ts`) instead of growing `site.ts`.
- Sections, in order:
  1. Hero: "Raycast extensions, inside your app." Subline: the engine builds,
     sandboxes and runs unmodified extensions; you draw views and answer the
     capabilities you grant. Buttons: "Try the live demo" (`/demo/`),
     "Quickstart" (GitHub `docs/quickstart.md`). Right side: a static mock of
     a rendered list next to the 4-line wire exchange that produced it.
  2. "The whole integration": a tabbed code block (no framework, plain
     `<details>`/radio tabs, works without JS) with JS in-process, Go, Python,
     Swift and "any language (NDJSON)" — each ≤ 15 lines showing open →
     launch → draw view → forward input. Take the JS and NDJSON snippets from
     `docs/embedding.md`/`README.md`; Go/Swift condensed from
     `examples/go-embedder`, `examples/macos-launcher/Sources/BlastKit`;
     Python as wire-level pseudocode-free real code using `subprocess`+`json`.
  3. "What Blast does / what you do" two-column list.
  4. "Runs everywhere": cards for Node/Bun/Electron, any language via
     `blast serve`, browser tab (sandboxed, by URL), terminal (TUI) — each
     linking to its example directory.
  5. Receipts: existing stats + links to `compat/COVERAGE.md`, `SWEEP.md`.
  6. Install: `npm install @blastlauncher/engine@next` and
     `npx -p @blastlauncher/serve@next blast-serve`.
- Keep it fast and dependency-free: no external fonts or scripts; one inline
  `<style>`; accessible headings; responsive at 360px; honours dark mode.
- 0153 is rewriting README/docs in parallel; link to `docs/quickstart.md`
  by URL even if it lands later.
