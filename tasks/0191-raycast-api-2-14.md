## Goal

`compat/` measures Blast against `@raycast/api@2.14.0` (latest on npm), the
shared `@raycast/utils` pin is `2.3.3`, and non-deprecated coverage is back to
100% with honest evidence for every symbol added since 2.11.1.

## Context

- The denominator is still 2.11.1 (`compat/raycast-api/source.json`).
  `bun run compat:upgrade 2.14.0` runs fetch → inventory → enums → stubs →
  report (`scripts/compat/upgrade.ts`). Network is allowed only inside these
  fetch scripts.
- After the upgrade, `compat/COVERAGE.md` lists what is new as `missing`. For
  each new or changed symbol: implement it in the shim/runtime/host where it
  belongs and add a test with `// @covers <Symbol.path>`. Follow how existing
  `@covers` tests in `packages/runtime` and `packages/host` are written.
- Look at the 2.11.1 → 2.14.0 diff of `compat/raycast-api/index.d.ts` for
  changed signatures and new enum members too, not only new top-level symbols.
- `@raycast/utils` pin: `packages/shared-deps/package.json`, plus the literal
  `2.3.2` in `scripts/corpus/selection.ts` (comment and hook list),
  `scripts/corpus/dependencies.test.ts` and `scripts/corpus/selection.test.ts`.
  Regenerate `bun.lock` with `bun install`; never hand-edit it. Check the
  hooks list in `selection.ts` against the 2.3.3 exports.
- Text references to `2.11.1` outside `compat/`: `README.md`, fixtures under
  `fixtures/` and the tests in `packages/host/src/index.test.ts` and
  `install-dependencies.test.ts`. Update the ones that state the coverage
  version; leave the ones that are only test data if they still pass.
- Runtime enums/stubs generated by `compat:enums` / `compat:stubs` are
  committed outputs; regenerate, never hand-edit.

## Acceptance

- [ ] `compat/raycast-api/source.json` has `"version": "2.14.0"`.
- [ ] `compat/COVERAGE.md` headline: non-deprecated 100.0% covered, 0 partial,
      0 missing. If a new symbol truly cannot be supported, mark it `partial`
      and explain why in Handoff, rather than adding a hollow test.
- [ ] Handoff lists every symbol added, removed or changed since 2.11.1 and
      what Blast did for each.
- [ ] `packages/shared-deps/package.json` pins `@raycast/utils` `2.3.3`;
      `bun install --frozen-lockfile` succeeds on the final commit.
- [ ] `README.md` states 2.14.0 as the measured version.
- [ ] `bun run verify` passes.
